# Callback Data

Этот каталог содержит клавиатуры бота и значения `callback_data`, которыми
клавиатуры связываются с обработчиками.

## Формат

Используйте формат:

```text
<домен>:<действие>[:<параметр>]
```

Примеры:

```text
user:select-role:tutor
points:award
points:award:123
```

## Правила

- Значения храните в `callbackData.ts`, а не дублируйте строковыми литералами.
- В TypeScript используйте `camelCase`: `callbackData.registration.roleTutor`.
- В значениях используйте только строчные слова и разделитель `:`.
- Первый сегмент обозначает домен: `user`, `points`, `user`.
- Второй сегмент обозначает действие или тип выбора: `role`, `award`, `delete`.
- Последующие сегменты используйте для параметров.
- Для фиксированных callback-значений добавляйте строковую константу.
- Для callback-значений с параметрами добавляйте шаблон или регулярное
  выражение для обработчика.
- Не используйте дефисы и пробелы в новых callback-значениях.
